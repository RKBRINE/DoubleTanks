# DoubleTanks

An **Outer Wilds** (OWML) mod that gives your spacesuit 2x capacity and thruster efficiency—with individual in-game toggles for every buff so you can customize how much extra leeway you want while exploring.

## Features
All options can be toggled live in the main menu under **Mods → DoubleTanks**:

* **Double Oxygen** (`2x`) — Cuts suit oxygen consumption in half, doubling how long you can survive outside breathable atmospheres.
* **Double Fuel** (`2x`) — Cuts jetpack fuel burn rate in half, doubling total flight time between refills.
* **Double Boost Duration** (`2x`) — Doubles how long a single jetpack boost charge lasts.
* **Double Air Boost Regen** (`2x`) — Doubles how fast your jetpack boost recharges while airborne.

## Installation
1. Install **[Outer Wilds Mod Manager](https://outerwildsmods.com/)**.
2. Search for **DoubleTanks** in the mod list and click **Install**.
3. Launch the game through the Mod Manager.

## Configuration
Open **Mods → DoubleTanks** from the Outer Wilds title screen to enable or disable any of the four multipliers individually. All four are enabled (`true`) by default.
